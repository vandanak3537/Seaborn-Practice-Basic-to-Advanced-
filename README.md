# Seaborn-Practice-Basic-to-Advanced-
## Overview

Practice repository for learning **Seaborn** and data visualization using Python.

## Topics Covered

* Scatter, Line, Bar & Count plots
* Box, Violin, Strip & Swarm plots
* Histograms & KDE
* Pairplot & Jointplot
* Heatmaps & Correlation
* `hue`, `style`, `size`
* Basic EDA

## Libraries

* Python
* Pandas
* Seaborn
* Matplotlib

## Project

**Student Performance Analysis**

Analyzed study hours, attendance, marks, departments, and grades using Seaborn and Matplotlib, with a final dashboard.
